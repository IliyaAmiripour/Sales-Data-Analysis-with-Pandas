#Sales-Data-Analysis-with-Pandas

📊 Sales Data Analysis with Pandas

A professional data analysis project built with Python and Pandas. This project demonstrates data cleaning, analysis, visualization, and report generation using a real-world sales dataset.

🚀 Features

Read CSV files using Pandas

Clean and preprocess data

Remove duplicate and missing values

Calculate total sales

Analyze monthly sales

Find top-selling products

Analyze sales by city

Generate CSV reports automatically

Create charts using Matplotlib

⚙️ Installation

Clone the repository:
git clone https://github.com/yourusername/sales-analysis.git 
Move into the project directory:
cd sales-analysis 
Install dependencies:
pip install -r requirements.txt 
Run the project:
python main.py

After running the project, the following files will be generated automatically:
